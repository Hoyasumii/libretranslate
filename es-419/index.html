TypeScript · LibreTranslate · MCP · CLI

Traducción de máquina de código abierto, final de tipo

No oficial TypeScript SDK para el LibreTranslate API, con un servidor MCP y un CLI construido sobre él. Úsalo de código, de un agente AI o de su terminal: los tres comparten el mismo cliente.

Empieza →GitHub
$ npm install @hoyasumii/libretranslate
@hoyasumii/libretranslate

SDK

Un cliente tipo para el LibreTranslate API, generada por orval de un espectaculo OpenAPI: traducción de texto y lotes, detección de idiomas, archivos, sugerencias, con la clave de API enviada para usted.

const lt = createLibreTranslateClient({ baseUrl: "http://localhost:5000" });
const { translatedText } = await lt.translate({ q: "Olá, mundo", target: "en" });
libretranslate-mcp

MCP server

Traducción automática para Claude Code, Codex, OpenCode o cualquier cliente MCP: textos, listas y documentos completos, detección de idiomas y herramientas genéricas para la API cruda. Sobre el HTTP esquivado o Streamable.

npx libretranslate mcp config
npx libretranslate mcp install
libretranslate

CLI

Cada herramienta MCP como comando terminal, además de libretranslate mcp para ejecutar el servidor en el fondo, iniciarlo en el login y registrarlo en sus clientes.

npx libretranslate translate --q "Olá, mundo" --target en
npx libretranslate translate-file --path report.docx --target es
